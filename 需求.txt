实现一个极简 iOS 视频播放器（自用，不上架）。

1. 技术栈：
Swift 5.9+ / SwiftUI / AVFoundation / AVKit / PhotosUI
主题固定暗黑（Theme 常量注入即可），无亮色/切换；黑灰 Zinc/Slate 系
图标优先 SF Symbols
状态：@Observable / Observation
网络暂不需要；本地相册 + 播放器即可
分发：免费 Apple ID 真机安装（不上 App Store）

2. 功能模块
- 极简视频播放器
  - 从 iOS 相册导入视频类型文件（PhotosPicker / PHPicker，仅 video）
  - 播放 / 暂停
  - 进度条（可拖动 seek）
  - 音频后台播放（UIBackgroundModes = audio；锁屏/切后台可续播，控制中心可暂停）
  - Loading / Empty / Error 三态；列表与播放器区域骨架屏，资源就绪后消失

3. 整体主题风格
固定暗黑色，不对用户提供主题切换
黑灰 Zinc/Slate 系，对齐 Linear / Stripe / Vercel 极简风
Theme 常量统一配色，禁止高饱和原生色；强制 `preferredColorScheme(.dark)`

4. 工程
- 根目录 `.gitignore`（通用 + Xcode/iOS）；详细规格见 `PRD.md`
- Xcode 工程结构建议：
  App / Features/Player / Core(Theme、Permissions) / DesignSystem

5. 整体页面布局
iPhone：工具/入口 → 内容页（NavigationStack）
首版可单页：上方播放器画布 + 下方控制条（播放暂停、进度）+ 导入入口
若后续扩展多工具，再升级为入口列表 → 详情

6. 加载与边界
各模块骨架屏 / .redacted；无视频时空态引导导入；权限拒绝与加载失败有明确 Error 态

7. 图标
默认 SF Symbols（play / pause / photo.on.rectangle 等）
